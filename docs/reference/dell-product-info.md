# Dell Wyse 3040 Thin Client — Product Notes

## Product identification

- Product: Dell Wyse 3040 thin client
- Order code: `ss3040thinospcoipfw_wow_8gf2gr_foxus`
- Captured Dell US price: `$428.00` at capture time; price and availability can change.
- Intended role: compact endpoint for virtual desktop and cloud-computing environments.

## Core hardware specifications

Dell’s support specification page identifies the following platform details:

- SoC/CPU: Intel Cherry Trail x5-Z8350, 1.44 GHz quad-core.
- Graphics: integrated graphics controller; dual-display support up to 2560 × 1600 at 60 Hz.
- Memory: 2 GB DDR3L-1600, soldered down.
- Storage: soldered 8 GB or 16 GB eMMC flash, depending on configuration.
- Networking: 10/100/1000 Base-T Ethernet. Optional WLAN/Bluetooth combo module: AzureWave AW-CM389MA with Marvell 8897, M.2 2230 SDIO interface.
- Operating systems/software listed in the support guide: ThinLinux 1.0.4, ThinOS 8.3.2, and PCoIP-enabled Wyse ThinOS.

## Ports and connectivity shown on the Dell product page

The port graphic labels these connections:

1. Composite audio jack
2. USB 2.0
3. USB 3.1
4. Power input
5. DisplayPort
6. USB 2.0
7. RJ-45 1 Gbps Ethernet

The product copy describes two DisplayPort interfaces, four USB ports in total, wired and wireless networking, and optional Bluetooth. The support specification separately lists two USB 2.0 ports and one USB 3.0 port in its port table, so the exact USB-generation wording should be treated as configuration/document-version dependent.

## Size, weight, power, and mounting

- Height: 27.94 mm / 1.1 in
- Width: 101.6 mm / 4 in
- Depth: 101.6 mm / 4 in
- Weight: 0.24 kg / 0.53 lb
- Power: the Dell product copy describes operation below 5 W. The support guide lists 5 V DC, 3 A and 12 V DC, 2 A input ranges, compliant with L.P.S.
- Chassis: sealed chassis; tool access required.
- Mounting: optional wall mount / VESA mount.
- Physical security: Kensington lock slot.

## Product-page feature claims

- Intel quad-core performance for virtual-desktop workloads.
- ThinOS support for virtual desktop brokers including Citrix, VMware, and Microsoft environments.
- Simplified automatic setup, configuration, and management.
- Optional PCoIP support for connection to Amazon WorkSpaces (AWS).
- Dell Wyse Management Suite for endpoint management.
- Compact, low-power design for cost-conscious deployments.
